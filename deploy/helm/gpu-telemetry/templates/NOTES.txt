GPU telemetry pipeline is installed via Helm (release {{ .Release.Name }}).

  kubectl -n {{ .Release.Namespace }} get pods,svc

Port-forward the gateway:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Release.Name }}-gateway {{ .Values.gateway.port }}:{{ .Values.gateway.port }}

  curl -s localhost:{{ .Values.gateway.port }}/healthz
  curl -s localhost:{{ .Values.gateway.port }}/api/v1/gpus | head
